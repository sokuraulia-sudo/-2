# ПТО — Система уведомлений о занятиях

Веб-страница, которая ведёт план обучения (тема, дата, ответственный, e-mail) и напоминает о занятии за сутки, в 15:15.

## Что внутри

- `index.html` — вся система в одном файле. Открывается прямо в браузере, отдельный сервер не нужен.

## Как пользоваться

1. Откройте страницу (локально или по ссылке GitHub Pages).
2. Нажмите **«📎 Прикрепить файл Excel»** и выберите план обучения (.xlsx). Ожидаются столбцы: **Тема**, **Дата обучения**, **Ответственный**, **адрес Эл почта**.
3. Когда до занятия остаются сутки (наступает 15:15), строка подсвечивается в блоке «Пора уведомить» — там же кнопка «Написать письмо» (mailto) и «Отметить отправленным».
4. Кнопкой **«📅 Скачать .ics»** можно выгрузить календарь с напоминаниями и импортировать его в Outlook / Google / Яндекс Календарь.

## Ограничение

Это статическая страница: она присылает напоминания, только пока открыта в браузере. Расписание сохраняется локально в браузере того, кто его загрузил (localStorage) — у каждого посетителя ссылки будет своя копия, пока он не загрузит тот же файл заново. Полностью автоматическая фоновая рассылка писем на почту требует отдельного сервера или подключённого почтового сервиса (например, Gmail/Outlook API по расписанию).

## Публикация на GitHub Pages

1. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
2. Через 1–2 минуты страница будет доступна по адресу `https://ваш-логин.github.io/название-репозитория/`.
